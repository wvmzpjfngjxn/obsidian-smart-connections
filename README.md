## Overview

Smart Connections builds a vector embedding index of your vault and surfaces semantically similar notes in a sidebar panel, enabling non-keyword discovery of related ideas across your knowledge base.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Obsidian Smart Connections** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Vector Embeddings** | Embed all vault notes into a local vector database for semantic search |
| **Similarity Panel** | Sidebar showing top related notes for the currently open file |
| **AI Chat** | Chat with your vault notes using local or API-based language models |
| **Embedding Update** | Incremental embedding updates process only changed notes |
